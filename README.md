# سباق الأبطال الأولمبي – لعبة تيك توك لايف التفاعلية

لعبة سباق عمودية (1080×1920) تعمل كـ Browser Source في TikTok LIVE Studio.
اللايكات تُدخل المشاهد في السباق (حتى 10 متسابقين)، والهدايا تمنحه دفعة سرعة كبيرة.

## هيكل الملفات
```
package.json
server.js            ← الخادم + الاتصال بتيك توك + منطق السباق
public/index.html    ← شاشة اللعبة (بدون أي أزرار)
public/style.css
public/game.js
public/host.html     ← لوحة المضيف (ربط البث، المدة، البدء/إعادة الضبط، اختبار)
```

## التشغيل محلياً
1. ثبّت Node.js 18 أو أحدث.
2. داخل مجلد المشروع:
   ```bash
   npm install
   npm start
   ```
3. افتح:
   - شاشة اللعبة: http://localhost:3000/
   - لوحة المضيف: http://localhost:3000/host.html
4. من لوحة المضيف اكتب اسم حسابك (بدون @) واضغط **اتصال** (يجب أن يكون بثك مباشراً).
   للتجربة بدون بث استخدم أزرار الاختبار في أسفل لوحة المضيف.

### متغيرات بيئة اختيارية
| المتغير | الفائدة |
|---|---|
| `HOST_PASSWORD` | يحمي لوحة المضيف بكلمة مرور (**مهم جداً بعد النشر**) |
| `TIKTOK_USERNAME` | يتصل تلقائياً عند تشغيل الخادم |
| `SIGN_API_KEY` | مفتاح Euler Stream لتحسين استقرار الاتصال |
| `PORT` | المنفذ (تضبطه الاستضافة تلقائياً) |

## النشر على استضافة مجانية (مثال: Render)
1. ارفع المشروع إلى مستودع GitHub.
2. في render.com: **New → Web Service** واختر المستودع.
3. الإعدادات: Build Command = `npm install` ، Start Command = `npm start` ، الخطة Free.
4. أضف Environment Variables: `HOST_PASSWORD` (وأيضاً `TIKTOK_USERNAME` إن أردت).
5. بعد النشر تحصل على رابط مثل `https://your-app.onrender.com`.
   - رابط اللعبة: `https://your-app.onrender.com/`
   - لوحة المضيف: `https://your-app.onrender.com/host.html`

> الخطة المجانية في Render تنام بعد ~15 دقيقة بلا زيارات؛ افتح الرابط قبل البث بدقائق،
> أو استخدم خدمة ping مجانية تستدعي `/health` كل 10 دقائق. بدائل: Koyeb، Railway، Fly.io.

## الإضافة في TikTok LIVE Studio
Add Source → **Web Page / Browser Source** ← الصق رابط اللعبة ← الأبعاد 1080×1920 (9:16).

## ملاحظات مهمة
- مكتبة `tiktok-live-connector` غير رسمية، وقد يحجب تيك توك عناوين IP الخاصة بمراكز البيانات أو يحدّ من الطلبات؛
  إن فشل الاتصال من الاستضافة جرّب `SIGN_API_KEY` أو شغّل الخادم محلياً.
- لا تتوفر بيانات جنس المستخدم في أحداث البث، لذا يُحدد الجنس عشوائياً بشكل ثابت لكل مستخدم. العلم يظهر فقط إن أرسل تيك توك بلد المستخدم.
- الشخصيات أصلية (غير مأخوذة من أنمي مسجّل).
- لوحة الصدارة موضوعة أسفل الشاشة لأن الشاشة عمودية.
